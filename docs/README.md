# Green Future Website

A modern environmental NGO website built with Next.js.

## Tech Stack

- Next.js
- React
- Tailwind CSS
- Framer Motion
- React Flow
- shadcn/ui
- DaisyUI
- Lucide React

## Modules

- Home
- Coverage
- Projects
- Videos
- Education
- Provinces
- About
- Contact
- Gallery

The Provinces module is designed as the showcase feature of the website.
